## Projects I have enjoyed building

### [Model Arena](https://github.com/avr5317/Model_Arena)

A local LLM evaluation platform built at the Podman AI Hackathon at the Red Hat building in Boston. I built the Streamlit frontend, the FastAPI endpoints, and the MCP server that exposes the pipeline to Claude Code. Three isolated Docker containers run Ollama for parallel inference, and models are compared on latency, BLEU-1, and a Claude-as-Judge rubric.

`Python` `FastAPI` `Streamlit` `Docker` `Ollama` `MCP`

### [Hear Me Out](https://github.com/avr5317/Hear-Me-Out)

An AI song generation platform built at the Frontier Hackathon, sponsored by Google DeepMind. A four stage agentic pipeline chains Claude Sonnet and Google Gemini, with each stage passing structured JSON context to the next. The FastAPI backend handles sessions and iteration history, and the demo shipped live within the 48 hour window.

`Python` `FastAPI` `Claude` `Gemini` `Three.js`

### [RescueRun](https://github.com/avr5317/Rescue_Run)

An AI mutual aid platform that parses and triages unstructured crisis data in real time. A FastAPI backend uses the Google Gemini API as an agent, and a React frontend with a Leaflet map shows the results. We built it in 48 hours and were shortlisted as one of the top 5 teams at the InnovAIte Hackathon.

`Python` `FastAPI` `Gemini API` `React` `Leaflet` `Tailwind CSS`

### [PAPI: Point-Cloud Analysis for Pathway Inclusion](https://github.com/avr5317/P.A.P.I-Point-cloud-Analysis-for-Pathway-Inclusion)

A data pipeline from BU Civic Hacks 2026 that analyzes 250 LiDAR sidewalk scans. Least squares plane fitting with NumPy surfaced 32,400+ ADA violations at 2m spatial precision, and the findings feed an interactive MapLibre GL dashboard backed by GeoPandas.

`Python` `NumPy` `GeoPandas` `LiDAR` `MapLibre GL`

### [Peter Lynch Investment Advisor](https://github.com/avr5317/peter-lynch-investment-advisor)

A RAG investment advisory chatbot built for the Generative AI course at Northeastern. It is trained on 5,000+ Q&A pairs about Peter Lynch's philosophy and uses a FAISS vector store with MiniLM embeddings and Llama 3.3 70B through the Groq API. K-Means clustering on live Yahoo Finance data produces Long and Short stock signals shown in Plotly charts.

`Python` `Streamlit` `LangChain` `FAISS` `Groq` `scikit-learn`

### [AI Super Hub](https://github.com/avr5317?tab=repositories)

A full stack learning platform built with a team of 4 engineers. It includes a directory of 70+ AI tools and a multi mode chatbot (General, Tutor, Coder, Summarizer) powered by the Google Gemini API. The Node.js backend uses JWT and RBAC, with Docker, CI/CD, and AWS S3, deployed on Vercel and Render. It earned the top project score in the course.

`React` `Node.js` `MongoDB` `Gemini API` `Docker` `AWS S3`

### [Community Issue Reporting and Resolution Management System](https://github.com/avr5317/Community-Issue-Reporting-Resolution-Management-System)

A Java desktop application built with a team of 4 for the INFO 5100 final project at Northeastern. It models a city as an ecosystem of independent enterprises such as Public Works, Utilities, and Public Safety, so a road technician who finds a burst pipe can escalate it straight to the Water Department as a linked work request. The system has 10+ user roles with role based dashboards, a notification center, and a manager analytics module that tracks resolution time and completion rates. Design patterns include Singleton, Factory Method, Strategy, and Observer.

`Java` `Swing` `NetBeans` `Design Patterns` `OOP`
